One-time setup: create a Google OAuth client

Resumeai talks to Google Docs and Drive on your behalf, so it needs an OAuth client tied to your Google Cloud project. This is a 5-minute, one-time setup that Google requires for any app that talks to your Drive — there is no way to skip it.

  1. Go to Google Cloud Console → Create project ↗. Name it anything (e.g. resumeai) and click Create.
  2. Open APIs & Services → Google Docs API ↗ and click Enable. Then enable the Google Drive API ↗ the same way.
  3. Go to OAuth consent screen ↗:
    • User type: External → Create.
    • App name: resumeai. Support email + developer email: your email.
    • Scopes: skip (we'll request what we need at runtime).
    • Test users: this is the bit that gets missed. Add your own Google account email (the one whose Docs you'll be tailoring) to the test-users list. Without this you'll get Error 403: access_denied on Connect Google because the OAuth consent screen ships in "Testing" mode and only lets listed users sign in.
  4. Go to Credentials ↗ → Create credentials → OAuth client ID:
    • Application type: Web application.
    • Name: resumeai local.
    • Authorised redirect URIs — add both of these so it works whether you visit via localhost or 127.0.0.1 (Google treats them as different URIs):
      • http://localhost:7842/api/auth/google/callback
      • http://127.0.0.1:7842/api/auth/google/callback
      {% if callback_url %}

      Your current session will use: {{ callback_url }}

      {% endif %}
    • Click Create. A dialog appears with your client ID and secret.
  5. Click Download JSON. You'll get a file called client_secret_…json. Open it in a text editor.
  6. Head back to Settings and paste the entire file contents into the OAuth client field.
